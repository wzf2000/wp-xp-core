# 安全政策 / Security policy

目前仅维护最新正式版本；修复不会自动部署到站点，站点管理员需要审查并更新。
Only the latest stable release is maintained. Fixes are not automatically deployed; site administrators review and install updates.

请通过 GitHub 的 [私密漏洞报告](https://github.com/wzf2000/wp-xp-core/security/advisories/new) 联系维护者。若入口不可用，请在 Issue 中仅提出建立私密联系的请求，不要包含漏洞细节，等待维护者提供私密渠道。
Use [GitHub private vulnerability reporting](https://github.com/wzf2000/wp-xp-core/security/advisories/new). If unavailable, open an Issue requesting a private contact channel without vulnerability details and wait for the maintainer's response.

报告应包含受影响版本、最小复现步骤、必要权限、预期影响和脱敏证据。请勿提供生产数据库、访问令牌、登录 Cookie、密钥或真实用户资料。使用隔离环境验证，避免对运行站点进行奖励、余额或权限测试。
Include affected versions, minimal reproduction steps, required permissions, impact and redacted evidence. Do not send production databases, tokens, cookies, secrets or personal data. Validate in an isolated environment without changing live rewards, balances or permissions.

维护者确认问题后会协调修复与披露时间；当前不承诺固定响应时限。
The maintainer coordinates fixes and disclosure after confirming a report; no fixed response time is promised.
